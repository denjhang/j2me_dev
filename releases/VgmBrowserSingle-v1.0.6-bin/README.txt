VgmBrowserSingle v1.0.6 (2026-10-21)
=====================================

 - 设置新增通道组音量：Square vol / Noise vol / Envelope vol（0-200%，步进 10%）
   噪声默认 150%（诺基亚噪声需额外增益的平衡补偿），方波/包络默认 100%
 - 设置重排，同类项靠近：
     播放:    Master / Engine / Gen size / Loop / Order
     通道平衡: Square vol / Noise vol / Envelope vol / Buzzer vol
     音准:    Octave / Bend sens / Bend range
     定位:    Stereo / Noise map
     包络:    Env saw/tri octave, Saw/Tri unison
     乐器:    10 个通道音色
 - 新设置项已持久化（RMS 兼容旧记录，缺省自动跳过）
