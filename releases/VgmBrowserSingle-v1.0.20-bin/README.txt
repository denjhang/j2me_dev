VgmBrowserSingle v1.0.20 (2026-10-21) — finalized defaults (E5 field-tested)
============================================================================

Defaults now set to the E5-verified sound:
 - Vol follow = CC7 (works on Nokia during long notes)
 - Noise map = C4 center (drums sit at middle C)
 - Square vol 90% / Noise vol 120% / Envelope(buzzer) vol 120%
 - Env saw octave +2

Note: old RMS records override these on first run - reset settings once
(or clear the MIDlet's RMS) to hear the new defaults.

All else same as v1.0.19.
