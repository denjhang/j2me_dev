VgmBrowserSingle v1.0.3 (2026-10-21)
=====================================

E5 (S60) 真机已验证可完美播放。本版针对真机反馈：
 - 新增 1M 缓冲档（S60 不限堆内存，可用大块进一步减少块切换次数）
 - 修复切曲内存泄漏：release() 时主动清空全部大块数据
   （事件流数组/SMF/寄存器池/烘焙图/解析器引用），不等懒 GC
 - 流数组自动收缩：容量超在留数据 8 倍时砍半，
   防止 dense 段落把峰值容量永久占用

其余同 v1.0.2：单缓冲水位线、扁平事件流、常驻预建线程、暂停不销毁、30fps。
安装：jar 直接拷到手机安装，无需签名。
